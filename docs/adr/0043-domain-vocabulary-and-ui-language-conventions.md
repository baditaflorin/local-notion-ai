# 0043 - Domain Vocabulary And UI Language Conventions

## Status

Accepted

## Context

Phase 2 substance requires the UI to describe domain behaviors rather than implementation details.

## Decision

Use user-facing terms such as:

- `High confidence`
- `Quoted history`
- `HTML boilerplate`
- `Table shape`
- `Action item`
- `Invoice identifier`

Errors must state what failed, why, and next step.

## Consequences

- The UI becomes more trustworthy on messy data.

## Alternatives Considered

- Continue using generic failure strings.
